PSX Wallet - Android app project
================================
Upload everything in this folder to a new GitHub repository. GitHub then builds
app-debug.apk for you in the cloud. See the steps given in the chat.

Important: package.json must be at the TOP LEVEL of the repository, and the hidden
folder ".github" must be uploaded too. If ".github/workflows/build-apk.yml" is missing
in your repository, create it on GitHub (Add file > Create new file, type
.github/workflows/build-apk.yml as the name) and paste the text from
build-apk.yml.copy.txt.
